# Interactive gallery

Explore the numbered curve and surface tutorials. Select a preview to rotate,
zoom, and change its display settings. One figure is active at a time so the
gallery stays responsive. Close it to return to the preview.

Use **Open full page** for a larger view, **Download HTML** for an offline copy,
or **Python source** to try the construction in the editor. The embedded figures
are read-only views; run the Python scripts to edit their control points.
