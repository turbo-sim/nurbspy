nurbspy.visualization.analysis module#

Native Python quantities and export previews for the geometry viewer.

nurbspy.visualization.analysis.colormap_tables()[source]#

Small display lookup tables; no Matplotlib window or pyplot is needed.

nurbspy.visualization.analysis.control_point_normal(geometry, index)[source]#

Native normal at the selected control point’s fixed Greville location.

This associates a parameter with a control point; it does not assert that the point lies on the geometry. Undefined normals are explicit nulls.

nurbspy.visualization.analysis.display_options(options, surface)[source]#

Validate optional initial UI settings; they never alter model geometry.

nurbspy.visualization.analysis.export_preview(geometry, nu=40, nv=40)[source]#

Generate one export mesh and encode the STL from that exact mesh.

nurbspy.visualization.analysis.frenet_frames(geometry, count=8, scale=0.1)[source]#

Sample native T/N/B frames at approximately equal arc-length intervals.

nurbspy.visualization.analysis.isocurve_parameters(geometry, direction, values)[source]#

Resolve fixed native parameters; None chooses five interior isocurves.

nurbspy.visualization.analysis.scalar_field(geometry, u, v, name)[source]#

Evaluate a selected field with native nurbspy derivatives and geometry.

Lengths use the model’s coordinate units. Arc length is cumulative numerical quadrature on a dense, knot-aware grid. Nonregular/undefined values are null in the JSON result, not invented zero values.

nurbspy.visualization.analysis.surface_isocurves(geometry, u, v, *, fixed_u=None, fixed_v=None)[source]#

Sample exact parameter curves together using the surface’s current grid.

A u-isocurve fixes u and varies v, matching get_isocurve_u(). The existing preview/full axes bound the work and retain knot samples without introducing independently editable curve snapshots.
