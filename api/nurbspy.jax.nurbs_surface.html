nurbspy.jax.nurbs_surface module#

Differentiable tensor-product NURBS surfaces with the NumPy surface API.

class nurbspy.jax.nurbs_surface.NurbsSurface(control_points=None, weights=None, u_degree=None, v_degree=None, u_knots=None, v_knots=None)[source]#

Bases: Module

A differentiable surface with paired parameters and NumPy-compatible shapes.

control_points has shape (ndim, Nu, Nv), and weights has shape (Nu, Nv). Omitting degrees makes a Bezier patch; omitted knots are open uniform. Values and derivatives have shape (ndim, N), including (ndim, 1) for scalar parameters. To evaluate a grid, flatten an ij meshgrid.

Degrees and control-net dimensions are static. Points, weights and knots remain differentiable array leaves. Normals and curvature require a regular three-dimensional patch; they are undefined at singular points. Pass changing parameters as arrays to reuse compiled evaluations; Python scalar arguments are static under eqx.filter_jit, as in JAX curves.

project_point_to_surface(P, maxiter=200, ftol=1e-06, gtol=1e-06, *, samples_per_span=8, xtol=1e-12)[source]#

Return a sampled single-start projection on the actual knot domain.

The closest sampled surface point starts one bounded local Newton solve. There is no multistart mode or hidden restart. gtol bounds tangent-scaled spatial stationarity relative to 1 + distance; ftol/xtol detect stagnation, never convergence on their own. A failed solve raises an error. Sampling cannot certify global optimality.

Exact implicit derivatives support query and geometry sensitivities at a locally unique regular minimum with stable active bounds. Weak-bound transitions, nonsmooth knots and singular reduced Hessians yield NaN sensitivities. The existing positional arguments remain supported.

project_points(points, maxiter=200, ftol=1e-06, gtol=1e-06, *, samples_per_span=8, xtol=1e-12)[source]#

Project (ndim,N) queries; sample geometry once, return (2,N).

Requires finite geometry, positive weights and continuous knot vectors. samples_per_span is an interior budget for each knot span/axis. See project_point_to_surface for convergence and AD assumptions.

nurbspy.jax.nurbs_surface.make_offset_surface(surface, offset)[source]#

Approximate S-offset*N with a sampled polynomial control net.

Match the NumPy algorithm: use ten times as many control points in each direction, retain the degrees, and use uniform clamped knots. This is exact for planes but is not an exact general NURBS offset construction.
