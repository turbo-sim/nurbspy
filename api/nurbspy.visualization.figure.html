nurbspy.visualization.figure module#

Reproducible figures using the shared native geometry model and Three.js viewport.

class nurbspy.visualization.figure.Figure(geometry=None, *, name='geometry', title='NURBS figure', resolution=None, preview_resolution=None, quality='auto', preview_quality='coarse', display=None, width=1000, height=750, background='#ffffff')[source]#

Bases: object

Named geometry snapshots, camera, display settings, and PNG export.

Numerical geometry stays in the existing NumPy/JAX classes. This object coordinates the existing per-geometry model; no numerical evaluator or second renderer is introduced. Geometry inputs and returned snapshots are independent.

savefig(destination, *, width=None, height=None, timeout=60)[source]#

Render a PNG without a visible window, with the saved framing and overlays.

A different output aspect ratio adds background margins; it never refits the geometry. Requires a Playwright Chromium engine or installed Edge/Chrome.

saveframes(frames, directory, *, width=None, height=None, prefix='frame', progress=None, timeout=60)[source]#

Export an iterable of Figures as PNGs while reusing one browser.

A generator can update and yield this same Figure on every iteration. Frames are rendered before the generator advances. progress(index, path) is called after each saved frame, with a one-based index.

scatter(points, *, color='#263238', size=3.0, depth_test=False)[source]#

Add read-only sample markers, retained in YAML and PNG exports.

Inputs have shape (dimension, count) or are a sequence of Point objects. Planar coordinates are promoted to z=0. Size is in logical pixels; depth_test=False makes markers an overlay visible above the surfaces. Markers are annotations, not editable NURBS geometry objects.

Export a standalone, read-only interactive HTML without a Python server.

Optional variants maps labels to Figures. Switching variants retains camera and display choices. Geometry/scientific calculations are frozen at export; navigation, appearance and layer visibility remain interactive.
