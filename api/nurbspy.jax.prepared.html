nurbspy.jax.prepared module#

Explicit reusable basis tables for fixed knots and evaluation parameters.

Preparation stores polynomial basis functions, not rational geometry. Control points and weights are supplied on every evaluation and remain differentiable. There is no hidden cache: rebuild a prepared object when knots, degree, sample locations or the required derivative orders change. If knots or parameters are optimization variables, keep preparation inside the differentiated function.

class nurbspy.jax.prepared.PreparedCurveBasis(basis: Array, degree: int, n_control: int, max_order: int)[source]#

Bases: Module

Reusable polynomial curve basis tables, constructed by prepare_curve.

basis has shape (min(degree,max_order)+1, n_control, n_samples). No control points or weights are retained. Omitting W means unit weights, including when the curve used for preparation originally had other weights. Evaluation can use any positive spatial dimension at the same control count.

nurbspy.jax.prepared.prepare_curve(curve, u, max_order=2)[source]#

Prepare polynomial basis rows for a curve’s fixed knots and samples.

Only degree, knots and control count are read from curve. Its points and weights are not retained. Supply both explicitly at evaluation for rational geometry. max_order is a static nonnegative integer and may exceed degree. Include this call inside AD when differentiating knots or sample parameters; preparing once outside that function intentionally fixes those inputs.

nurbspy.jax.prepared.prepare_surface(surface, u, v, max_order_u=2, max_order_v=2, *, grid=False)[source]#

Prepare factorized polynomial basis rows for fixed surface parameters.

grid=False uses scalar or equal-length paired arrays, like NurbsSurface. grid=True uses independent 1D u/v axes and returns an ij tensor grid. Only 1D basis tables are stored in either mode. Control points and rational weights are always explicit evaluation inputs. Rebuild for new knots/samples; include preparation inside AD if their sensitivities are required.
